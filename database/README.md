# Banco de dados

**Oracle fornecido pela faculdade**, acessado por JDBC (decisão de 12/11/2026). O esquema será gerenciado por scripts SQL em `scripts/` (criação, carga sintética e consultas), com a finalidade e a ordem de execução explicadas em cada script. Dados de conexão ainda pendentes; não versione credenciais (use `DB_URL`, `DB_USERNAME` e `DB_PASSWORD`).

`docker-compose.yml` e a configuração de PostgreSQL pertencem à fundação antiga e **não serão usados**; podem ser removidos na migração.
