# Contrato: convenções documentais

Lista de verificação aplicada a cada documento mantido (SC-003). Cada item é aprovado ou reprovado.

| # | Convenção |
|---|---|
| C1 | Idioma português-BR, sem mistura com inglês exceto termos técnicos convencionais |
| C2 | Um H1; hierarquia de títulos sem saltos |
| C3 | Logo após o H1, uma linha de propósito; documento derivado declara sua fonte de verdade |
| C4 | Datas em prosa `DD/MM/AAAA`; em nomes de arquivo `AAAA-MM-DD` |
| C5 | Nomes de arquivo em minúsculas com hífen; exceções listadas e justificadas no inventário |
| C6 | Links relativos válidos; sem caminho absoluto de máquina |
| C7 | Status explícito: implementado, testado, documentado ou planejado, sem afirmar conclusão sem evidência |
| C8 | Termos de domínio consistentes (solicitação, documento, extração, conferência, análise, pendência, submissão simulada) |
| C9 | Simulado identificado onde IA, extração/OCR ou sensores aparecem |
| C10 | Dados fictícios identificados; nenhum dado real, segredo ou credencial |
| C11 | Documento aparece em exatamente um índice |
| C12 | Sem trecho de 3 ou mais linhas copiado de outro documento (usar referência) |
